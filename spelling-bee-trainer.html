Take it with you

All 320 words as an Anki deck

Six fields per note: the word, its IPA, the Spanish, the definition, an example sentence, and the etymology with its spelling trap. The export follows the lists and levels you have selected above. Copy the block below, or use the .txt files saved next to this app.

  1. Copy the text below, paste it into a plain text file and save it as spelling-bee.txt with UTF-8 encoding.
  2. In Anki: File → Import, choose that file.
  3. Set Field separator to Tab and tick Allow HTML in fields.
  4. Map the six fields in order, pick your deck, and import. Tags carry the level (basic, intermediate, advanced), the list (opening or tiebreak) and the origin language.
